PWA de Retail para Cadena de Ferreterías

Aplicación web progresiva de gran escala para una importante cadena argentina de ferreterías.

Responsabilidad

Diego lideró el desarrollo con un equipo Agile XP de cuatro personas, participando en decisiones técnicas, coordinación de la entrega y evolución del producto.

Tecnología

  • ASP.NET MVC y JavaScript
  • AWS y DynamoDB
  • Arquitectura PWA
  • Agile XP
